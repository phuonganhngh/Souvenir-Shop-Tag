# プライスタグ一括作成ツール

登別グランドホテルの見本と、14商品のリスト（List.xlsx）をもとにした、日本語の操作画面を持つツールです。翻訳済みの商品リストをExcelから取り込み、内容を確認・編集して、プライスタグをまとめて印刷できます。自動翻訳は行いません。GoogleやOpenAIのAPIキー、翻訳サービスの契約は不要です。

## Web版の使い方

1. 管理者から案内されたWebサイトのURLを開き、パスワードでログインします。HTMLやZIPを端末にダウンロードする必要はありません。
2. 日本語・英語・韓国語・簡体字・繁体字の商品名と価格を入力した `.xlsx` ファイルをアップロードします。商品シートを自動で選択して取り込みます。「Excelテンプレート」から見出しと記入例を確認できます。
3. 商品名をクリックすると、商品ごとに名称、価格、税表示・備考を編集できます。Excelの翻訳はそのまま取り込み、空欄は空欄のまま保持します。取り込みは現在のリストを置き換えるため、編集内容を残す場合は先にExcelへ書き出してください。
4. 印刷対象にチェックを入れ、部数とタグのサイズを選びます。ホテルのロゴは固定されており、変更・削除・アップロードのボタンはありません。ロゴと縁の模様は、提供されたPNGテンプレートをそのまま使用しています。
5. 「印刷・PDF保存」をクリックします。**A4・縦向き・倍率100%**にし、背景のグラフィックを有効、ヘッダーとフッターを無効にしてください。PDFを作成する場合は、印刷先で「PDFに保存」を選択します。大量に印刷する前に1ページを試し刷りして寸法を確認してください。
6. 編集後のリストは編集欄の「編集した商品リストをExcelに書き出す」から保存できます。元のExcelファイルは上書きしません。書き出したファイルにはすべての商品と編集済みの名称・価格・備考が含まれ、印刷部数や画面設定は含まれません。
7. 共有端末では「ログアウト」で終了してください。

「追加」から商品を手入力することもできます。商品名、翻訳、価格、商品のサイズ・種類、税表示は印刷前に確認してください。「税込」は価格に税が含まれることを確認した場合のみ入力してください。税表示が空欄の場合は自動で追加しません。

タグのサイズは90×55 mm（1ページ8枚）、100×60 mm（1ページ4枚）、180×110 mm（1ページ2枚）です。A4用紙の余白は10 mm、タグ間の裁断用スペースは4 mmです。長すぎる商品名・備考は、プレビューで確認して調整してください。

### Excelの形式と制限

- 対応形式は `.xlsx`。最大5 MB・2,000商品です。
- 1行目に `日本語` と `価格 (JPY)` が必要です。`English`、`한국어`、`简体中文`、`繁體中文（台灣）`、`価格表示・備考` は任意です。列の順序は変更できます。
- Notesシートは商品リストとして取り込まないでください。
- 価格は日本円（JPY）の0以上の整数です。
- 商品ごとに最大100部、1回の印刷につき合計1,000枚までです。
- 自動翻訳、マクロの実行、Excel数式の再計算は行いません。数式はExcelに保存済みの計算結果だけを読み取ります。

### データの保存

商品データの読み込み・編集・印刷・Excel書き出しはブラウザー内で処理し、外部の翻訳サービスに送信しません。編集内容は端末・ブラウザーのlocalStorageに保存されます。端末間での自動同期はありません。プライベートブラウズやローカルファイルの利用時には保存が制限される場合があるため、重要な内容はExcelに書き出してください。ログアウトはサーバーのログイン状態を終了する操作であり、端末内の商品リストは削除しません。共有端末から商品データも消したい場合は、先にExcelへ保存し、「この端末の保存データを削除」を使用してください。

## Web版の公開（Vercel）

1. VercelにGitHubアカウントでログインし、「Add New → Project」から `phuonganhngh/Souvenir-Shop-Tag` を取り込みます。
2. Application Presetは**Vite**、Root Directoryは既定値、Node.jsは**24**、Build Commandは `npm run build`、Output Directoryは `dist` です。
3. 「Environment Variables」に**`APP_PASSWORD`だけ**を登録します。値は8文字以上の推測されにくいパスワードにしてください。Vercelの設定画面で直接入力し、コード・HTML・GitHub・チャットには貼り付けないでください。
4. 「Deploy」を押し、完了後に「Visit」で開きます。発行されたHTTPS URLとパスワードを利用者に案内してください。
5. パスワードを後から追加・変更した場合は「Redeploy」で適用します。GitHubへの更新が自動デプロイに接続されている場合は、mainブランチへの変更が反映されます。

ログインは署名付きHttpOnly Cookieで8時間維持されます。パスワード変更後の再デプロイにより旧セッションは無効になります。パスワードをHTMLに埋め込む方式ではありません。GitHubの公開コードや別途配布するHTMLファイル自体は、このWeb版の認証では保護されません。

翻訳機能は削除済みです。以前 `GOOGLE_TRANSLATE_API_KEY` をVercelに登録していた場合は削除できます。Google Cloudの有効化や請求設定は不要です。

GitHubをPublicにする操作とWebサイトの公開は別です。このプロジェクトでは、パスワードを保持するためVercelを使用します。GitHub Pagesではサーバーによるパスワード認証を実行できません。

## 開発者向け

Node.js 24が必要です。

```sh
cd /workspace/-Tag
npm ci --cache /workspace/.npm-cache
npm run dev:api
# 別のターミナルで実行
npm run dev -- --port 5173
```

サーバーの環境変数に `APP_PASSWORD` を安全に設定し、開発時は `/api/session` でログインします。Viteは `/api` をポート8787へ転送します。本番用の通常のNode.jsサーバーでは以下を実行します。

```sh
npm run build
npm start
```

既定ポートは8787です。`PORT`で変更できます。本番ではHTTPSのリバースプロキシを使用してください。

```sh
npm test
npm run test:browser
npm run test:access
npm run build
npm run build:portable
```

ブラウザーテストにはChromiumが必要です。既定は `/usr/bin/chromium` で、`CHROMIUM_PATH`で変更できます。`test:browser`の前にポート5173でアプリを起動してください。接続先は`APP_URL`、確認するExcelは`EXCEL_FIXTURE=/path/to/List.xlsx`で変更できます。既定では同梱の14商品からワークブックを作成します。`test:access`はテスト用サーバーを起動し、ログイン・ログアウトを検証します。

`dist/` はWeb公開用です。利用者はWebサイトからそのまま作業できます。必要な場合のみ、代替のオフライン版として [Price-Tags.html](downloads/Price-Tags.html) をGitHubの「Download raw file（↓）」で取得し、ChromeまたはEdgeで開けます。ZIPの展開やインストールは不要です。フォントとライブラリを含むため約24 MBです。オフライン版ではサーバーによるパスワード保護は利用できません。配布版を更新する場合は `npm run build:portable` の後、`portable/index.html` を `downloads/Price-Tags.html` にコピーしてください。

Notoフォントはローカルに同梱され、SIL Open Font Licenseが適用されます。タグ背景は提供された元画像 `src/assets/tag-template.png`（1075×650）を加工せず使用します。この画像にロゴと金色の縁模様が含まれるため、別のロゴ画像やCSSの模様を重ねません。背景はプレビューと印刷の両方に画像として表示し、その上にExcelの商品名・価格・備考を配置します。以前の縁模様の有効・無効設定、旧ロゴや自動翻訳の設定がlocalStorageに残っていても使用しません。

クラウド環境はタスクごとに分離されています。既存のチェックアウトを使用し、ユーザーから明示的な依頼がない限りGit worktreeを作成しないでください。新しい環境ではプロセスの再起動が必要です。Vercelの公開URLでの動作は、デプロイ後に確認してください。
