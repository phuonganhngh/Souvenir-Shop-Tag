# プライスタグ一括作成ツール

登別グランドホテルのプライスタグ見本と、14商品のリスト（List.xlsx）をもとに作成した、日本語の操作画面を持つツールです。Excelの読み込み・編集・印刷はブラウザー内で行います。Web版では共通パスワードでログインし、日本語の商品名から4言語へ自動翻訳できます。自動翻訳にはGoogle Cloud Translationの設定が必要です。

## HTML ファイルのダウンロード

[Price-Tags.html をダウンロード](downloads/Price-Tags.html)してください。GitHub のファイル画面で **Download raw file（↓）** をクリックし、保存した HTML ファイルを Chrome または Edge で開きます。ZIP の展開やインストールは不要です。フォントとライブラリを含むため、ファイルサイズは約24 MBです。非公開リポジトリの場合は、閲覧権限のある GitHub アカウントでログインしてください。これはダウンロード版であり、公開 Web サイトの URL ではありません。

配布版を更新する場合は、`npm run build:portable` を実行し、生成された `portable/index.html` を `downloads/Price-Tags.html` にコピーしてください。

## ご利用方法

1. パソコンの Chrome または Edge で **Price-Tags.html** を開きます。インターネットに接続していなくても利用できます。保存済みのリストを引き続き編集する場合は、同じブラウザーを使用してください。
2. 初期リストを使用するか、**追加** から手入力します。Excel から取り込む場合は、**Excelテンプレート** でテンプレートを取得し、商品情報を入力してアップロードします。シートを選択して **シートを取り込む** をクリックしてください。取り込みにより現在のリストが置き換わるため、編集内容を残す場合は、事前に **使い方** から Excel に書き出してください。
3. Web版では「取込後に空欄を自動翻訳」を有効にすると、日本語の商品名から英語・韓国語・簡体字・繁体字の空欄を補完します。既存の翻訳は上書きしません。手入力後や失敗時は「空欄を翻訳」で再実行できます。商品名をクリックして内容を編集し、印刷する商品にチェックを入れて部数を指定します。価格、商品名、翻訳、商品のサイズ・種類、税表示を確認してください。「税込」は、価格に税が含まれると確認できた場合のみ入力してください。Excel の税表示欄が空欄の場合は、空欄のまま取り込まれます。
4. タグのサイズを選択します。ホテルのロゴはアプリに固定で組み込まれており、アップロード・変更・削除するボタンはありません。縁の模様は見本を参考に再現したものです。
5. **印刷・PDF保存** をクリックします。印刷設定を **A4・縦向き・倍率100%** にし、**背景のグラフィックを有効**、**ヘッダーとフッターを無効**にして、プレビューを確認してください。PDF を作成する場合は、印刷先で **PDFに保存** を選択します。大量に印刷する前に、1ページを試し刷りして寸法を確認してください。

タグのサイズは、90×55 mm（1ページ8枚）、100×60 mm（1ページ4枚）、180×110 mm（1ページ2枚）です。A4 用紙の余白は10 mm、タグ間の裁断用スペースは4 mmです。文章が長すぎる場合は、プレビューを確認し、内容を短くするか適切な位置で改行してください。

### Excel の形式と制限

- 対応形式：`.xlsx`。ファイルサイズは最大5 MB、商品データは最大2,000行です。
- 印刷部数は商品ごとに最大100部、1回の印刷につき合計1,000枚までです。
- 価格は日本円（JPY）の0以上の整数で入力してください。
- 1行目の見出しには `日本語` と `価格 (JPY)` が必要です。`English`、`한국어`、`简体中文`、`繁體中文（台灣）`、`価格表示・備考` は任意です。列の順序は変更できます。
- Notes シートは商品リストとして取り込まないでください。
- マクロの実行やExcel数式の再計算は行いません。数式のセルについては、Excel に保存済みの計算結果のみを読み取ります。

### データの保存

データは使用中の端末・ブラウザーの localStorage に保存されます。プライベートブラウズやローカルファイルの利用時には、保存が制限される場合があります。重要なデータは、画面を閉じる前に Excel に書き出してください。書き出される Excel には商品情報のみが含まれ、印刷部数、印刷対象の選択、画面設定は含まれません。端末間での自動同期はありません。

## 開発者向け

Node.js 24が必要です。

```sh
cd /workspace/-Tag
npm ci --cache /workspace/.npm-cache
npm run dev:api
# 別のターミナルで実行
npm run dev -- --port 5173
```

```sh
npm test
npm run test:browser
npm run test:access
npm run build
npm run build:portable
```

ブラウザーテストには Chromium が必要です。既定の実行ファイルは `/usr/bin/chromium` で、`CHROMIUM_PATH` で変更できます。テストの前に、ポート5173でアプリを起動してください。接続先は `APP_URL` で変更できます。実際の Excel ファイルを使って確認する場合は、`EXCEL_FIXTURE=/path/to/List.xlsx` を指定してください。既定では、同梱の14商品からテスト用ワークブックを生成します。

`dist/` は HTTPS 対応のホスティングサービスに配置できる静的サイトです。`portable/index.html` はコード、ライブラリ、フォントをすべて1ファイルにまとめたもので、`Price-Tags.html` に名前を変更して配布し、ブラウザーで直接開くことができます。オフライン版では自動翻訳とサーバーによるパスワード保護は利用できません。Noto フォントはローカルに同梱されており、フォントパッケージ内の SIL Open Font License が適用されます。

クラウド環境はタスクごとに分離されています。既存のチェックアウトを使用し、ユーザーから明示的な依頼がない限り Git worktree を作成しないでください。新しい環境ではプロセスを再起動する必要があります。コードとインストール済みの依存関係は、スナップショットによって保持される場合があります。

固定ロゴには、提供された元画像 `src/assets/hotel-logo.png` を使用しています。この画像は Vite によってサイトに組み込まれ、オフライン版 HTML にも埋め込まれます。固定ロゴが上書きされないよう、localStorage に残っている旧ロゴの設定は使用しません。


## Web版の公開（Vercel）

GitHubをPublicに変更するとコードを閲覧・ダウンロードできるようになりますが、Webサイトの公開とは別の操作です。GitHub Pagesは静的なExcel編集・印刷版には利用できますが、サーバーでの翻訳とパスワード認証は実行できません。

1. VercelにGitHubアカウントでログインし、「Add New → Project」からこのリポジトリを取り込みます。
2. フレームワークはVite、Node.jsは24、ビルドコマンドは`npm run build`、公開先は`dist`です。リポジトリ内の`vercel.json`と`middleware.js`を使用します。
3. Vercelの「Settings → Environment Variables」に以下を登録します。値はVercelの設定画面でのみ入力し、コード・HTML・GitHub・チャットには貼り付けないでください。
   - `APP_PASSWORD`：利用者に案内する共通パスワード。8文字以上で、推測されにくいものにしてください。
   - `GOOGLE_TRANSLATE_API_KEY`：Google Cloud Translation用のAPIキー。
4. Google Cloud側でCloud Translation APIと請求設定を有効化します。APIキーはCloud Translation APIに用途を制限し、利用料金・割り当て上限を設定してください。このサービスにはGoogle Cloudの利用料金が発生する場合があります。
5. 「Deploy」を実行し、発行されたHTTPS URLを利用者に案内します。変数を後から追加・変更した場合は再デプロイしてください。
6. パスワードでログインし、日本語と価格だけのExcelを取り込んで、翻訳・編集・Excel書き出し・印刷を確認します。共有端末では「ログアウト」で終了してください。

利用者はAPIキーを入力する必要がありません。ログインは署名付きのHttpOnly Cookieで8時間維持されます。パスワード変更後の再デプロイにより旧セッションは無効になります。HTMLにパスワードを埋め込む方式ではありません。ダウンロード版のHTMLとGitHubに置かれたコード自体は、このWeb版の認証では保護されません。

### 自動翻訳の仕様

- 送信するのは日本語の商品名と翻訳先のみです。Excelファイル全体、価格、税表示、備考は送信しません。
- 翻訳済みの欄は保持します。日本語名を変更して再翻訳したい場合は、対応する翻訳欄を空にして「空欄を翻訳」を押してください。
- 同じ商品名はリクエスト内で重複排除し、最大50商品・翻訳先込み20,000文字ごとに分割します。日本語の商品名は500文字以内です。
- エラー時も日本語データと翻訳済みの内容は保持します。追加済みの翻訳は保存され、残りの空欄のみ再試行できます。
- 機械翻訳は正式な商品名と異なることがあります。印刷前に確認し、必要に応じて修正してください。価格と税表示は翻訳しません。
- 本番ではGoogle Cloud側のAPI割り当て上限を設定してください。アプリのプロセス内レート制限はサーバーレス環境全体で共有される厳密な上限ではありません。

### 通常のNode.jsサーバーで実行する場合

サーバーの環境変数に`APP_PASSWORD`と`GOOGLE_TRANSLATE_API_KEY`を安全に設定してから、以下を実行します。秘密の値をコマンド引数や共有スクリプトに記載しないでください。

```sh
npm ci
npm run build
npm start
```

既定ポートは8787です。`PORT`で変更できます。本番ではHTTPSのリバースプロキシを使用してください。開発時は`npm run dev:api`と`npm run dev`を別のターミナルで起動し、`/api/session`でログインします。

テストでは翻訳サービスの応答を模擬しており、Googleへの実接続や翻訳品質を検証したものではありません。実際のAPIキーとデプロイ先が未設定の場合、ライブ翻訳と公開URLの動作確認は未完了です。
